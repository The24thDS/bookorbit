# AGENTS.md

Guidance for AI coding agents working in this repository.

## Agent skills

### Issue tracker

Issues live in GitHub (`The24thDS/bookorbit`); use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels, each named its role (`needs-triage`, `needs-info`,
`ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
